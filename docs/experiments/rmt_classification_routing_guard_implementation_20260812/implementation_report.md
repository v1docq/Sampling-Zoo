# Защищённый селектор геометрии маршрутизации для классификации

## Результат этапа

В существующий перекрёстно проверяемый селектор добавлены ограничения для задач классификации. Селектор по-прежнему сравнивает `A5_gmm_posterior` и `A6_cosine_negative_control` с опорным вариантом `A2_median_scaled_euclidean`, но теперь не может принять улучшение основной метрики, если оно сопровождается недопустимым ухудшением калибровки или качества редкого класса.

Для бинарных задач основной метрикой служит ROC AUC, а допустимое ухудшение задаётся в абсолютной шкале. Для многоклассовых задач используется относительное изменение log loss. Дополнительные ограничения проверяют Brier score, ожидаемую ошибку калибровки, macro F1 и минимальную полноту среди классов.

## Архитектурные решения

- Сырые результаты каждого внутреннего фолда преобразуются в неизменяемые `RoutingGeometryFoldScore`.
- Метрики-ограничения представлены отдельными `RoutingGeometryGuardMetricScore`.
- Политика проверки задаётся через `ClassificationRoutingGuardSpec` и не зависит от кода загрузки данных или обучения моделей.
- Решение остаётся детерминированным и использует только внутреннюю валидацию; внешний тестовый набор не участвует в выборе.
- При отсутствии обязательной метрики или несовпадении пар фолдов используется явный откат на A2.

## Проверка

Выполнено 58 тестов. Проверены положительные примеры, откат при ухудшении полноты худшего класса, относительная шкала log loss, перестановочная инвариантность, вероятностные метрики и прежний регрессионный путь.

Следующий шаг: полный запуск на трёх бинарных и трёх многоклассовых задачах AMLB, пяти начальных значениях генератора и четырёх бюджетах. Ожидается 480 записей.
