# Результаты синтетической проверки топологий тела и сигнала

## Постановка

Проверка охватывает семь режимов данных, три значения отношения сигнал/шум (SNR), три доли бюджета и пять начальных значений генератора. Для каждой комбинации сопоставлены четыре варианта:

- `B0_standard_A9` — стандартная топология RMT с выбором геометрии маршрутизации по внутренним удерживаемым фолдам;
- `B1_bulk_single_spike` — один эксперт для тела распределения и один эксперт для сигнала;
- `B2_bulk_multi_spike` — один эксперт для тела и несколько экспертов для устойчивых сигнальных компонент;
- `B3_validation_selected` — защищённый выбор между B0, B1 и B2 без обращения к тестовой части данных.

Диагностический вариант B4 вычисляет верхнюю границу качества при построчном выборе лучшего эксперта. Он не считается отдельным запуском. Полная сетка содержит 1260 записей.

## Проверенные гипотезы

Первая, мягкая версия селектора использовала только валидационные показатели. Она завершила все 1260 запусков, но не прошла критерий допуска:

- доля возврата к B0 на нулевом режиме и режиме ложного спектрального выброса составила 72,2% при пороге 80%;
- худшее ухудшение достигло 20,9%;
- следовательно, одних валидационных показателей недостаточно для безопасного выбора специальной топологии.

Вторая версия ввела двойной допуск. Сначала проверяется наличие устойчивых сигнальных компонент и фактически сформированных экспертов. Затем кандидат должен показать положительную нижнюю границу доверительного интервала, средний выигрыш не менее 1%, медианный выигрыш не менее 0,5% и победу не менее чем на 80% внутренних фолдов.

## Итог строгого селектора

Строгий селектор прошёл все заранее заданные проверки:

| Показатель | Значение |
|---|---:|
| Завершённые записи | 1260 из 1260 |
| Доля возврата к B0 на нулевых режимах | 96,7% |
| Число выборов B1/B2 | 17 |
| Доля побед среди выбранных B1/B2 | 94,1% |
| Медианный выигрыш среди выбранных B1/B2 | 19,3% |
| Худшее изменение среди подтверждающих запусков | -0,09% |
| Ложные многоветочные эксперты | 0% |

Точный общий бюджет и уникальность строк соблюдены во всех запусках. Вероятности классификации корректно нормированы. Метрика инвариантна к совместной перестановке строк, а итоговый прогноз — к согласованной перестановке экспертов и их весов.

## Вывод

Синтетическая проверка разрешает переход к пилоту на реальных данных только для строгого `B3_validation_selected`. Мягкий селектор остаётся отрицательной контрольной гипотезой. B1/B2 нельзя включать без спектрального допуска: даже убедительное локальное улучшение на валидации не защищает от крупного ухудшения на тестовой части.

Артефакты мягкой версии находятся в `../rmt_bulk_spike_topology_full_20260812/`, строгой версии — в `../rmt_bulk_spike_topology_full_strict_20260812/`.
