# План серверной исследовательской программы RMT

`research_program_plan.json` сформирован напрямую из типизированных контрактов
`RMTBulkSpikeResearchProgramConfig` и `ResearchProgramPlan`. Он фиксирует семь
этапов, их зависимости, жёсткие критерии перехода и ожидаемое число записей.

Общий объём до итоговой аналитики составляет 4720 записей вариантов. Часть
из 1600 записей плотной бюджетной сетки переиспользует совместимые результаты
полной AMLB-сетки. Полнообъёмные эталоны хранятся отдельно и не умножаются на
число бюджетов.
