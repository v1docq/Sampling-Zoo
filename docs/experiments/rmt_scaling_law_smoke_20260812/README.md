# Smoke-проверка законов масштабирования RMT

Каталог подтверждает работоспособность полного пути
`эксперимент -> полнообъёмный эталон -> аппроксимация -> таблицы -> график`.
Исходный запуск содержит две синтетические задачи, одно начальное значение
генератора и бюджеты `5%`, `10%`, `20%`. Отдельная модель, обученная на всём
обучающем разбиении, служит точным якорем при бюджете `100%`.

## Состав артефактов

- `source/` содержит 24 записи вариантов B0--B3, два полнообъёмных эталона и
  инкрементальные журналы запуска;
- `analysis/scaling_law_points.csv` содержит наблюдаемые и аппроксимированные
  значения функции потерь;
- `analysis/scaling_law_fits.csv` и `scaling_law_fits.json` содержат параметры
  кривых, качество аппроксимации и оценку требуемого бюджета;
- `analysis/scaling_law_report.md` содержит сводную таблицу;
- `analysis/scaling_law_curves.png` содержит визуальную проверку кривых.

## Ограничение интерпретации

Это проверка программных контрактов, а не подтверждение закона
масштабирования. При трёх частичных бюджетах и одном начальном значении
генератора оценки могут упираться в границы допустимого показателя степени.
Такие случаи имеют статус `boundary_limited`; остальные разреженные оценки
имеют статус `exploratory_sparse_grid`. Статус `supported` допустим только на
плотной сетке как минимум из шести бюджетов, с несколькими начальными
значениями генератора, хорошим качеством аппроксимации и показателем степени,
лежащим внутри заданного интервала.
