# Phase S.1: условный выбор строк

## Что реализовано

Добавлен типизированный селектор, который разрешает `capped_leverage` только при наличии устойчивых перекрёстно проверяемых свидетельств. Опорной политикой остаётся `uniform`, поэтому отрицательный или неполный результат не меняет принятое безопасное поведение.

Официальный эксперимент содержит три варианта: `U0_uniform`, `C1_capped_leverage` и `S1_conditional`. Для `S1_conditional` используется геометрия A9. Решение на фиксированной геометрии A2 вычисляется из тех же обученных моделей и сохраняется как контрфактическая диагностика, поэтому согласованный объём официальной сетки остаётся равным 480 записям.

## Условия выбора capped leverage

- нижняя граница доверительного интервала выигрыша не ниже `-0.5%`;
- положительный выигрыш наблюдается не менее чем на двух третях внутренних фолдов;
- ухудшение хвостовой ошибки не превышает `1%`;
- для классификации сохраняется покрытие классов.

На уровне полного пилотного эксперимента кандидат должен выбираться не менее чем в `10%` случаев и выигрывать не менее чем в `70%` выбранных случаев.

## Проверка

Пройден 21 тест. Проверены точный размер официальной сетки, направления RMSE и ROC AUC, ограничения на хвостовую ошибку и покрытие классов, детерминированность относительно порядка фолдов и практический критерий допуска.
