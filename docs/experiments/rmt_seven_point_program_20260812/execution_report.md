# Итоги семи проверок RMT-семплирования

Дата завершения: 12 августа 2026 года. В отчёт включены только результаты с
полной сеткой, уникальными ключами запусков и нулевым числом вычислительных
ошибок. Критерии допуска фиксировались до анализа соответствующей полной серии.

## Краткий итог

| Этап | Статус | Решение |
|---|---|---|
| Независимая проверка A9 | пройдена | Рекомендовать A9 для регрессии с обязательным возвратом к A2 |
| Машиночитаемый критерий A9 | пройден | Пороги не изменять |
| Точный leverage-sketch | реализован | Использовать как исследовательский механизм, не как политику по умолчанию |
| Синтетическая Phase S | пройдена | Гипотеза `robust mixture + IPW` допустима к проверке на реальных данных |
| Phase S на реальных данных | не пройдена | Сохранить uniform как политику по умолчанию |
| Композиция с Leverage SHAP | не пройдена | Сохранить как независимую проверку качества объяснений |
| Идентифицируемость bulk/spike | пройдена | Допустить топологию с точным бюджетом к пилоту на реальных данных |

Всего проверено 1582 основных экспериментальных записи: 320 для независимого
A9 holdout, 252 для синтетической Phase S, 180 для полной Phase S на реальных
данных, 800 для Leverage SHAP и 30 для bulk/spike diagnostics.

## 1. Независимое подтверждение A9

Holdout использовал новые задачи `house_16H`, `house_sales`, `pol` и
`topo_2_1`, бюджеты `(0.01, 0.05, 0.10, 0.20)`, пять значений генератора и
пять внутренних фолдов. Внешняя тестовая выборка не участвовала в выборе
геометрии.

- завершено 320 из 320 записей, ошибок и повторяющихся ключей нет;
- A9 выбрал A2 47 раз, A5 — 17 раз, A6 — 16 раз;
- 32 из 33 небазовых решений улучшили основную метрику;
- средний выигрыш относительно A2 равен `+6.025%`, медианный — `0%`;
- неотрицательная медиана получена на всех четырёх датасетах;
- худшее изменение основной метрики равно `-0.0052%` при пределе `-0.5%`;
- худшее изменение `TailMAE` равно `-0.7392%` при пределе `-1%`.

Большой средний эффект обусловлен задачей `pol`: медианный выигрыш растёт от
`+10.91%` при бюджете 1% до `+44.95%` при бюджете 20%. На остальных задачах
A9 чаще возвращается к A2; небольшие положительные средние значения возникают
в редких случаях безопасного выбора A5 или A6. Единственное ухудшение основной
метрики составило `-0.0052%` на `house_16H`.

Вывод: A9 прошёл проверку безопасности и полезности на независимых
регрессионных задачах. Его следует использовать как селектор, а не как новую
фиксированную геометрию: A2 остаётся обязательным резервным вариантом.

## 2. Leverage-preserving семплирование строк

Численный слой реализует насыщенные вероятности включения с точным бюджетом,
зависимое округление без повторяющихся строк, `uniform`, capped leverage,
robust mixture и ridge leverage, а также обратное вероятностное взвешивание
(IPW). Для контроля
сохраняются ошибки матрицы Грама, стоимости проекции и главные углы
подпространств.

В классификации точные IPW разрешены только для пропорционального распределения
бюджета по непересекающимся классам. Последовательная политика
`minimum_then_global` не выдаёт условные вероятности второго этапа за точные
первые вероятности включения.

## 3. Синтетическая Phase S

Все 252 запуска завершены с точным бюджетом и уникальными строками. Вариант
`S5_robust_mixture_ipw` показал средний выигрыш `+0.04172`, медианный
`+0.02262`, выигрыш в худшем сценарии `+0.00467` и уменьшил ошибку матрицы
Грама в среднем на `0.18516` относительно uniform.

Контроль с теми же строками без IPW дал средний результат `-0.25643`. Значит,
на синтетических линейных задачах эффект принадлежит согласованной паре
«вероятности включения + скорректированный функционал обучения», а не одному
порядку строк по leverage-оценке.

## 4. Phase S на реальных данных

Полная серия содержит 180 из 180 записей на `diamonds`,
`OnlineNewsPopularity`, `bank-marketing` и `covertype`. Все варианты используют
один и тот же A9-селектор геометрии; меняются только строки и режим весов.

| Вариант | Средний выигрыш | Медианный выигрыш | Доля побед | Ошибка матрицы Грама |
|---|---:|---:|---:|---:|
| `R0_uniform` | `0.00000` | `0.00000` | `0.0%` | `0.19734` |
| `R1_capped_incumbent` | `-0.00713` | `-0.00392` | `41.7%` | `0.17250` |
| `R2_robust_mixture` | `-0.00791` | `-0.00557` | `25.0%` | `0.04243` |
| `R3_robust_mixture_ipw` | `-0.00806` | `-0.00744` | `30.6%` | `0.04243` |
| `R4_ridge_leverage_ipw` | `-0.01715` | `-0.00926` | `33.3%` | `0.04607` |

Гипотеза переноса не подтвердилась. `R2`, `R3` и `R4` примерно в четыре раза
лучше сохраняют матрицу Грама, но проигрывают `uniform` по итоговой метрике
LightGBM. Ранговая корреляция между улучшением матрицы Грама и выигрышем
основной метрики равна лишь `0.255`, линейная — `0.072`. Для одинаковых строк
IPW меняет результат `R3` относительно `R2` в среднем на `-0.00015`, медианно
на `-0.00039`, с долей побед 50%; устойчивого преимущества коррекции нет.

Положительные области существуют, но не образуют общей политики. Например,
`R1` выигрывает на `diamonds` при бюджете 10% и на
`OnlineNewsPopularity` при бюджете 20%. Поэтому следующий кандидат —
валидационный выбор между `uniform` и capped leverage, а не безусловная замена
`uniform`.

## 5. Leverage SHAP

Эксперимент разделяет семплирование строк для обучения и семплирование
коалиций признаков для SHAP-регрессии. Все 800 запусков соблюдают точный бюджет
и ограничение эффективности, однако общий критерий преимущества Leverage SHAP
не пройден: медианный выигрыш относительной ошибки равен `-0.00088`, средний
`-0.00064`, доля побед — `48.2%`.

Это не опровергает теоретическую гарантию исходной статьи: текущий протокол
сравнивает конечнобюджетную ошибку Shapley values на нескольких типах игр, а не
только взвешенный регрессионный функционал. Leverage SHAP остаётся полезным
независимым контролем объяснений, но не основанием для выбора строк обучения.

## 6. Bulk/spike diagnostics

Синтетический критерий идентифицируемости пройден на 30 из 30 комбинаций
гауссовского шума и шума Student-t. При `SNR >= 1` медианная ROC AUC
определения строк с сигналом выше `0.999`, а обогащение таких строк в
выделенном бюджете находится между `1.875` и `2.604`.

Результат подтверждает, что реализованная диагностика различает участие строк
в spike-компонентах. Он ещё не доказывает преимущество двух типов экспертов на
реальных данных, поэтому следующий опыт должен сохранять общий бюджет и тот же
внешний тест.

## 7. Решения и следующий этап

1. Зафиксировать A9 как рекомендуемый регрессионный селектор с обязательным
   возвратом к A2 при недостаточной уверенности.
2. Оставить равномерный выбор строк политикой по умолчанию.
3. Не включать IPW для LightGBM без отдельного модельно-зависимого критерия.
4. Реализовать валидационный выбор `uniform` или `capped leverage` как
   отдельную Phase S.1, используя непересекающийся внутренний holdout.
5. Перейти к пилоту bulk/spike-топологии на реальных данных: один широкий bulk
   expert, несколько spike experts и точный общий бюджет.
6. Сначала выполнить пилот на четырёх задачах и бюджетах
   `(0.01, 0.05, 0.10, 0.20)`, затем допускать полную сетку только при
   неухудшении основной и хвостовой метрик.
7. Сохранить Leverage SHAP как отдельную ось проверки объяснимости и не
   смешивать её критерий с качеством семплирования строк.
